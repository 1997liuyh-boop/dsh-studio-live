# 新会话操作工作室

安装并启用共享运行时、工作室容器和项目插件后，普通 dsh 会话会获得 `studio` 工具。无需为普通操作预先绑定 Toonflow 项目会话。

例如：“打开影音工作室，选择电影、日本、动画、2025 年，按评分排序。”AI 先查询工作室目录，再打开页面、读取控件并逐步点击。每一步都返回真实页面快照；网络请求尚未结束时继续读取，不以点击成功代替内容加载成功。

主窗口输入 `@` 可以选择已启用的工作室，引用在提交时序列化为 `@工作室:id`；工作室停用后，旧引用会要求重新选择。悬浮球也提供 `@` 候选，可输入 `@旅行 帮我规划路线` 或 `@影音工作室 找日本动画`。选择候选只补全输入，继续输入要求后再发送；两处都在当前 dsh 会话中调用同一个 `studio` 工具。悬浮球历史使用主窗口的未归档会话目录，切换、改名和进行中的消息同步，不再展示独立桌面操作历史。

## 协议

- `list`：读取当前已登记插件的标识、名称和说明。
- `open` / `read`：打开或读取工作室，返回正文和最多 100 个控件；`offset` 可继续读取后面的控件。
- `click` / `fill` / `select`：只接受最近快照中的 `target`，填写内容或选择真实选项。
- `scroll`：滚动页面或指定控件，支持上下左右。

控件编号随页面快照更新，页面刷新后旧编号失效。不得推测控件编号、提交脚本或选择器。密码、令牌、密钥和文件上传由用户手动处理。删除、付费生成等操作遵循用户授权及原应用确认，不绕过确认界面。

## 插件接入

插件通过 `studioProjects.register({ id, name, icon, description, root })` 登记，停用即从目录移除。运行时自动向插件 HTML 注入 `packages/sdk/controlBridge.ts` 的构建产物。同源页面无需增加业务代码。

嵌入本机原应用时，外层唯一应用 iframe 标记 `data-studio-app`；加载阶段标记 `data-studio-loading="true"`。原应用也需加载控制桥。CineFlow 随 Electron 网页预加载桥接入；Toonflow 与 Printfilm 的入口及 `public/studioControl.js` 已包含在各自适配补丁中。

控制消息使用 `dsh:studio:control` 和 `dsh:studio:controlResult`，校验父子窗口、来源、请求编号和到期时间。仅允许同源父页面、桌面宿主 `dsh-app://app` 及本机 5173 开发页面。其他 Web 宿主端口应显式加入允许列表后重新构建。

## 运行边界

主窗口领取内存队列中的操作并保留当前会话，AI 打开工作室时显示聊天。主窗口关闭、工作室未安装或原应用未连接时返回错误。任务取消或超时后不再派发；已经触发的写操作无法自动撤销，超时后先读取结果再决定下一步。

此桥调用页面现有控件，未暴露为控件的业务能力仍需项目自己的工具。已有 Toonflow 项目会话的画布工具继续按原项目范围使用。
